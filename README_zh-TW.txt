石牌車站 AR 明信片｜觸控、俯仰與固定觀看更新版（v3）

上傳
解壓縮，將裡面的全部檔案與資料夾覆蓋到石牌網站的 GitHub Main，與 index.html 放在同一層。保留 assets、vendor 資料夾結構。GitHub Pages 使用 main / root，手機以 HTTPS 開啟並允許相機。
更新後「調整模型」應出現「側面」「從上看」「固定觀看」及俯仰角按鈕。若沒有，請重新整理或清除快取；JS、CSS 已使用新的版本網址。

操作
1. 按「開始掃描明信片」，對準包內 print_photo.jpg；保留整張照片，避免裁切及反光。
2. 雙指張合：放大／縮小模型（0.25 至 2.5）。
3. 單指左右拖曳：改變方向；單指上下拖曳：調整俯仰。向上拖曳可降低觀看角度。
4. 雙指轉動：改變方向，可同時縮放。俯仰範圍為 -85° 至 35°。
5. 「側面」立即切到較低角度，可繼續拖曳微調；「從上看」恢復俯視。旋轉到另一側可觀看火車與鐵軌。
6. 「固定觀看」固定目前模型在畫面中的位置與姿態；之後的照片追蹤不會再驅動它，照片離開鏡頭仍可觀看、播放動畫與操作模型。
7. 固定觀看時，移動手機不會繼續對齊照片。按「恢復追蹤」重新貼合照片；若照片已離開鏡頭，模型會隱藏，等待重新辨識。
8. 「調整模型」保留動畫暫停／繼續。速度、大小、方向、俯仰及高度改成按鈕，沒有滑軌。
9. 「恢復預設」還原模型設定、恢復動畫播放及照片追蹤。「結束掃描」會關閉相機並清除固定觀看狀態。

本次更新
套用人力車新版相同的手勢、俯仰、固定觀看及姿態穩定處理：分別平滑位置、旋轉與尺寸，忽略很小的變化，攔下單次異常跳點，持續且一致的位移仍會接受。
MindAR 設定為 filterMinCF 0.001、filterBeta 20、warmupTolerance 8、missTolerance 8。
平滑可能讓跟隨鏡頭稍慢；固定觀看會停止照片對位。一般追蹤模式的穩定度仍須在手機上測試，不能保證所有環境完全不晃。
